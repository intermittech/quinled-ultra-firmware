# Round 4 prototype acceptance additions — firmware 0.6.4 (gpt-mutation; the flash rows updated for 0.6.4)

All rows are **not verified on hardware**. These are proposed acceptance tests, not measurements.
Use the actual rev04 board, its fitted current-sense gain and fuse, calibrated instruments, and a controlled load.
Record firmware/toolchain hashes, supply, load, PWM preset, spread/dither/floor settings, raw scope files and serial log.
Test 12/24/48 V within board ratings; run the normal 24 V / 25 kHz case and the 48 V / 100 kHz corner.
Instrument D9/PB15 as a temporary timing marker if needed; do not add a DMA channel or repurpose an LED output.

| Priority / item | Method and expected result | Pass / fail criterion |
|---|---|---|
| P0 — every flash writer while illuminated (0.6.4 policy) | Hold five distinct nonzero duties above 15 % and repeat below 15 % (dark, dim) and during a breathe / colour effect and a slow fade-up. Trigger automatic settings saves, scene appends and page fills, calibration-record saves, effect-store commits, lifetime-record writes (regular / dark / dip), the console's `save`, and the update confirmation. Scope timer / driver inputs, one FET drain, input current and a photodiode; mark each flash operation (D9 / PB15 as a temporary marker). Include an adaptive slew in progress. Expected (Quindor 2026-10-14, WCH RM 32.1): during an erase or program HCLK is halved, so the PWM carrier runs at half frequency with the duty unchanged, for the operation's time only; erases happen only while every output is below 15 % (500 ms steady, nothing rising), at power-up or never; while brighter only programs into pre-erased entries, at most one per hour; at a supply dip programs only. | No extra / missing pulse, frozen or replayed transition, all-off interval or visible blink. The half-frequency carrier is expected and must last only the operation (measure it: half-words x the program time per half-word, an erase ~16 ms typical): report the longest window per path and per admission state (low / bright / dip). No erase while any output is at or above 15 %. Duty within one timer count of the baseline. The console line in progress is cancelled when bytes arrive during an operation (expected). Requested calibration / identify / update-reset indications are identified separately from housekeeping. |
| P0 — real ISR publication ordering | Continuous WS and Ultra frames, randomized relative phase, maximum supported frame rate; simultaneously exercise settings saves, period/stagger changes, phase slews and trips. Run release LTO at gain 100/50 as fitted; scope all gate inputs and FWD_EN/DIN/DOUT. Expected: no half-published plan/table, stale capture or deadlocked slew. | Zero wrong channels/slots, uncommanded pulses, watchdog resets or stuck output over 1 million frames per exercised mode; every induced trip turns off all five driver inputs. Source guards do not prove this row. Read back TIM2 CC1E/CC2E/CC3E = 0 and USART3 RE = 0. |
| P0 — fast trip and recovery on silicon | Apply controlled current steps below/above the compiled `fast_raw` level; scope PA7 (after its RC), shunt current and five driver inputs. Sweep phase against the 50 us poll. Include short pulses, saturation, and a fault during calibration. Expected: two consecutive samples at/above threshold force outputs off; one sample or a level below threshold does not. | From the PA7 threshold crossing, trip within the specified 50–100 us sampling interval plus measured ISR/driver latency; report that latency separately. Do not use this as a 100 us guarantee from the physical fault: amplifier/RC/PSU delay is additional. All channels stay off for the 1 s retry, then 2/4/8/16/32 s for persistent faults, with soft start when released. Faults during calibration report failure and never store a completed test. Failure below threshold or an absent trip is a failure. |
| P0 — limiter, overload and ADC interruptions | Step/fade a load above the configured board limit without a short; repeat over PWM presets and spread settings while voltage/temperature injected conversions and flash writes occur. Record ADC windows, current and all PWM outputs. Expected: one shared scale preserves colour; sustained current above `overload_level()` trips after 200 ms. | No false fast trip on allowed load steps, no missing trip for 200 consecutive qualifying 1 ms readings, no channel-specific blink. Retry and scale agree with recorded current. Accept steady current only within the programmed limit plus the specified feedback/model margin and instrument/ADC uncertainty; report overshoot and settling time rather than inventing a bound. |
| P1 — invalid/marginal data and gate timing | Drive both WS2915 header lengths, WS2805 and Ultra through 1, 3 and ultimately 50 boards. Sweep DIN pulse-width corners, inter-frame gaps and phase; truncate, corrupt CRCs, inject an internal reset gap, and change protocols while saves occur. Scope DIN/DOUT/FWD_EN. | Good frames reach the correct board/slot; rejected input does not apply arbitrary output values. No spurious forwarding edge or partial downstream slot from a save. Gate edge-to-FWD_EN delay stays below the README's approximately 400 ns limit; report measured maximum. Every DMA/capture counter counts all valid edges. |
| P1 — actual DMA table ownership | Slow fades across native-step, minimum-pulse and off-time boundaries at all presets, left/right alignment, three dither modes and three floor policies. Simultaneously update two channels on each shared burst timer. Test spread on/off and active adaptive slew. | No torn table or other channel's compare value, no on/off sliver shorter than the configured floor except when FLOOR_OFF is explicitly selected, no uncommanded dark/full-on pulse, no visible restart of a repeating pattern. Average compare duty meets the documented dither/floor quantization bound, with probe uncertainty recorded. |
| P1 — signal loss during effects | Breathe near its minimum and maximum, RGB strobe during a colour transition, colour loop, candle and sunrise. Disconnect the host with loss mode fade; repeat with hold and immediate off. Scope/photodiode the transition. Expected: fade starts at the displayed colour/level; hold keeps effects running; immediate off is dark. | No initial bright or colour flash. Fade decreases to off in 1 s; hold is continuous; immediate-off response follows the configured loss timeout plus the next main-loop render. Repeat with a pending future effect, overlapping lights, dim-to-warm and current limiting. Patch 03 fixes a reproduced host-level start discontinuity; this row verifies the full output path. |
| P1 — flash fault / power-loss recovery (0.6.4: A/B pairs) | Cut supply at several points in a record append, an erase of the other page (due and ahead), the effect store's header-last write and the confirmation. Reboot and inspect settings / calibration / scene / effect / lifetime. Repeat both erased read patterns (0xFFFF, 0xE339) and at page boundaries. Also: a write-protect or stuck-BSY error (if inducible) reports `flash: error` and leaves the record pending. | Only a complete CRC-valid record or the previous one is used: settings, calibration, scene log and lifetime record are A/B page pairs, the page holding the newest record is never erased, so a cut at any point keeps the last complete record (0.6.3 could lose the settings / calibration at a page erase). The effect store loses its effects only during its own two-page rewrite (documented). No invented light mask, unsafe calibration or mixed update descriptor. Flash read-after-write (FLASH_VERIFY 1 build) and the SRAM shadow behaviour are verified rather than assumed from the host's RAM model. |
| P1 — update sessions while lit | Rejected/old/wrong-hardware/CRC-corrupt ANNOUNCE, interleaved session halves, aborted sessions, repeated PING and confirmation failure. Scope PWM and forwarding. Then separately install a known TEST image. | Rejected/partial/aborted sessions never install or borrow FORCE from another session; UPD traffic counts as signal and transparency exits after 2 s. No output disturbance on forwarding/PING/rejection/confirmation. Accepted installation's intentional reset/bootloader interval is logged separately. The settings/calibration/scene/effect/energy regions survive a compatible update. |
| P2 — current model / calibration health | Known loads and a meter at all four calibration levels, one disconnected channel, changed cable resistance, and voltage changes. Compare restored records after reset; use the same load for limit/adaptive stagger. | Correct no-load/normal/abnormal classifications and monotonic measured curves; no calibration stored after a trip. Proposed metrology acceptance: within max(20 mA, 2% of reading) plus meter uncertainty. Any saturation or systematic error is reported and requires gain/threshold investigation; do not silently loosen protection limits. |
| P2 — energy write and brownout margin | Meter a known V x I load for 1 h and test both heavily and lightly loaded turn-off after more than 1 Wh. Scope supply, PA4, flash marker and PWM. | Energy agrees within the measured voltage/current error budget; recovered lifetime value is a complete valid record. Confirm whether the dip-triggered write finishes before reset. If it cannot, report the actual lost interval; hourly/dark writes are the fallback, not proof of successful dip persistence. No housekeeping-induced blink. |
| P2 — real clock/long-duration behavior | 52-day run: one board with Ultra effects, one with a power-on effect/no host, one WS board. Log status twice daily and retain waveform windows around tick/ms wraps; inject only planned load/dip/config events. | No watchdog reset, frozen/replayed effect or unexplained power event. Uptime increases, stack remains safely below 2048 B, and stored-record counts respect budgets. Hardware time/drift must agree with elapsed wall time; sparse host-soak jumps do not prove timing under real DMA/interrupt load. |

P0 flash continuity is stricter than “the light looks unchanged”: PWM timing and asynchronous fades are part of
the primary output function. 0.6.4 accepts the halved carrier for the operation's time only (Quindor's decision,
WCH RM 32.1; ask WCH about the datasheet's 60 MHz HCLK note); measure that window, do not infer it.
